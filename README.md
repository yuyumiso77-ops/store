# 매장 상품 피드백 조사

매장에서 판매하는 상품에 대해 고객 의견을 모으고, 관리자 화면에서 결과를 확인하는 웹 앱입니다.
외부 패키지 없이 Node.js(18 이상)만 있으면 실행됩니다.

## 실행

```bash
ADMIN_PASSWORD=원하는비밀번호 npm start
```

- 고객 설문: http://localhost:3000
- 관리자 화면: http://localhost:3000/admin (아이디는 아무거나, 비밀번호는 `ADMIN_PASSWORD`)

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `ADMIN_PASSWORD` | `admin1234` | 관리자 비밀번호 (**꼭 바꾸세요**) |
| `DATA_DIR` | `./data` | 데이터 저장 폴더 (`db.json`) |

## 사용 방법

1. 관리자 화면에서 판매 중인 **상품을 등록**합니다.
2. 상품별 **QR 코드**를 인쇄해서 진열대나 계산대에 붙입니다.
   고객이 QR을 찍으면 해당 상품이 미리 선택된 설문이 열립니다.
3. 고객은 아래 항목에 답합니다.
   - 전체 만족도, 품질, 가격 만족도 (별 1~5개)
   - 재구매 의향 (있음 / 고민 중 / 없음)
   - 연령대, 자유 의견 (선택)
4. 관리자 화면에서 상품별 평균 점수, 별점 분포, 재구매 의향 비율, 최근 의견을 확인합니다.
   평균 만족도가 가장 낮은 상품은 "개선이 필요한 상품"으로 표시됩니다.
5. **CSV 내려받기**로 전체 응답을 엑셀에서 열 수 있습니다.
6. 판매가 끝난 상품은 **설문 중지**를 누르면 설문 목록에서 빠집니다. 기존 응답은 그대로 남습니다.

## 테스트

```bash
npm test
```

## 참고

- 고객이 휴대폰으로 접속하려면 서버가 같은 Wi-Fi 네트워크나 인터넷에 공개된 주소에서 실행되어야 합니다.
- QR 코드 생성 라이브러리는 CDN(cdnjs)에서 불러옵니다. 인터넷이 안 되면 QR 대신 설문 주소가 표시됩니다.
